LUMINA AI SCHOOL — PHOTO FOLDER
================================

Drop your photos into this folder (assets/images/) using the EXACT filenames
below. The website already looks for these names — once a matching file is
added, it replaces the placeholder automatically. No code changes needed.

LOGO (appears in the header and footer on every page)
------------------------
  logo.png              -> DONE — your icon mark, background removed,
                            already in place and live on the site.
  logo-full.png          -> Bonus: the full lockup (icon + "LUMINA" /
                            "SCHOOL" text baked in), background removed too,
                            in case you want it for a larger placement
                            (e.g. a splash screen or printed materials).
                            Not currently used anywhere on the site.

HOME PAGE — ABOUT US SECTION (index.html)
------------------------
  classroom.jpg         -> Photo next to the "About Us" text on the home
                            page. Until this file exists, the site shows a
                            styled placeholder instead of a broken image.

RECOMMENDATIONS
----------------
- Use .jpg or .png
- Landscape (4:3 or 16:9) works best for classroom.jpg
- Keep each file under ~2MB for fast loading

If a file is missing, the site quietly falls back to a styled placeholder
instead of showing a broken image — so it's safe to upload these gradually.
